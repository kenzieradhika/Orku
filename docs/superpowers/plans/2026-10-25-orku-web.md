**Goal:** Add tested PHP-native SSR, assets, protected forms and working demo.

Explicit helpers and immutable render contexts; native lazy sessions.
**Tech Stack:** PHP 8.4+, existing PHPUnit/PHPStan/PHP CS Fixer; no runtime packages.
**Spec:** `docs/web-architecture.md` and user's v0.2 requirements.

## Global constraints

- Preserve 71 Core tests and every existing public contract.
- No mandatory Node, DB, compiler, JS framework, or sessions on read-only pages.
- No eval, automatic arbitrary PHP escaping claims, unsafe-inline, unsafe-eval.
- No commits/pushes; retain preexisting work.

## Review focus

- Nested failures must restore buffers and keep contexts isolated.
- Symlinks must not escape trusted roots; deployments own trusted filesystem.
- Malformed UTF-8, duplicate/bracket fields and numeric overflow fail predictably.
- Session cookie path/TLS policy and invalid CSRF must work through real HTTP.
- Prefix deployments, HEAD, conditional asset requests and safe HTML errors.
