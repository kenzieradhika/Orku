# Orku Core v0.1 Implementation Plan

> **For agentic workers:** Use executing-plans to implement task-by-task. User requested autonomous execution; no commits or pushes.

**Goal:** Deliver tested, executable PHP 8.4 HTTP vertical slice, not future modules.

**Architecture:** Immutable HTTP values, registration-time route pattern parsing, explicit request passed to handlers. Kernel maps exceptions to JSON errors; SAPI adapter captures globals and emits responses. Runtime has no Composer dependencies.

**Tech Stack:** PHP 8.4+, Composer PSR-4, PHPUnit 12.5, PHPStan 2, PHP-CS-Fixer 3, GitHub Actions.

**Spec:** User's master development prompt, Milestone 1. Architecture decisions recorded in docs/architecture.md.

## Global Constraints

- PHP 8.4+; MIT; strict typing; no runtime dependencies beyond ext-json.
- No frontend engine, database, container, middleware, worker, route compilation, or performance comparisons in v0.1.
- Existing repository empty. Preserve unrelated work. No commits or pushes.

## Review Focus

- Malformed paths and encoded separators produce 400, never route confusion.
- Header injection and invalid status codes fail before output.
- JSON null is valid; malformed JSON and oversized payloads produce safe errors.
- HEAD, method mismatch, duplicate routes, trailing slashes have deterministic semantics.
- Reused kernel never retains route parameters or diagnostics from previous request.
